# LOOMI Studio

Website resmi LOOMI Studio, studio pembuatan website performa tinggi untuk UMKM Indonesia berbasis di Jepara.

## Teknologi

- **Framework**: Next.js 15 (App Router, Static Export)
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS
- **Desain**: Scandinavian High-Contrast Editorial (Fraunces & Inter)
- **Komunikasi & Pemesanan**: WhatsApp Order Direct Builder

## Memulai Pengembangan

Jalankan perintah berikut untuk menginstal dependensi dan menjalankan server lokal:

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

## Build Produksi

Untuk menghasilkan file statis siap hosting:

```bash
npm run build
```

Hasil build statis akan tersimpan di direktori `out/`.
